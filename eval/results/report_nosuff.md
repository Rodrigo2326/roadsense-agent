Selector tokens are the tool-choosing model's. For the `llm` arm they are Bedrock tokens billed exactly like the writer's, so that arm's true token bill is both rows added together. For the `decider` arm they are not billed per token at all -- Decider 2B runs on an EC2 instance charged by the hour. The rows are kept apart so those two costs are never silently summed.

Bedrock cost is reported as token counts, not dollars: no rate for this model could be verified from the AWS Pricing API or the public pricing page, and inventing one would make the only priced number in the table the unreliable one. Add rates to `pricing.json` to price it. The Decider arm additionally consumes EC2 time, which is an hourly cost on self-managed compute rather than a per-call charge.
